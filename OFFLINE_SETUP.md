# Xentrix Offline Setup Instructions

To run the Xentrix utility platform offline from the packaged ZIP file:

1. **Extract**: Download `xentrix-final-offline.zip` and extract its contents to a directory on your local machine.
2. **Install Dependencies**: Open a terminal in the extracted directory and run:
   ```bash
   npm install
   ```
3. **Build**: Build the platform by running:
   ```bash
   npm run build
   ```
4. **Start Server**: Start the local development server:
   ```bash
   npm run dev
   ```
5. **Access**: Open your web browser and navigate to `http://localhost:3000`.

*Note: Ensure Node.js is installed on your local machine.*
