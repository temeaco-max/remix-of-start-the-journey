# Kurukoo Repository Red-Team Report — 2026-08-18

## Executive assessment

The repository is structurally coherent and the canonical service boundaries are substantially protected. The red-team sweep passed the web build, route and security contracts, PWA contract, public runtime contracts, accessibility audit, strict CSS audit, mobile TypeScript, mobile lint and the deterministic mobile suite. The work does not prove external provider activation, real-device notification delivery, production credentials, provider fulfilment or live payment settlement.

## Defect fixed during this red-team

`src/services/contactSyncService.ts` contained hardcoded phone-to-name metadata and deterministic generated names. That could fabricate personal identity data if the background service ran against real profiles. The service now fails closed, exposes explicit readiness through `KURUKOO_CONTACT_SYNC_ENABLED` and `KURUKOO_CONTACT_SYNC_SOURCE=trusted_provider`, performs no mutation until a trusted adapter and consent boundary are implemented, and is protected by `test:contact-sync-boundary`.

## Residual warnings and boundaries

The mobile lint command emits a non-failing Node module-type warning for `eslint.config.js`; this is not a validation failure. Earlier Metro watcher diagnostics were stale process output and were not reproduced by fresh TypeScript, lint or Vitest runs.

The following remain external activation gates: JWT secret configuration, Firebase/FCM registration and real-device proof, WhatsApp or Telegram provider sessions and callbacks, SMS/email delivery, Gemini/Mistral credentials and quota review, Stripe production webhooks and settlement, WebRTC relay, MQTT broker, verified providers, inventory and dispatch, KYC, and durable production worker hosting.

## Decision

Kurukoo is repository-side ready for controlled deployment preparation, not universally live. Any release process must supply the external credentials, privacy decisions, provider verification, durable hosting and real-world delivery evidence listed above before those capabilities are described as active.
