## Current-Main Implementation Priorities

The next client-only packages follow the confirmed P0/P1 ordering: shared tokens and primitives; Chat density and anchored composer; Discover and Nearby Radar; Requests, Checkout and Confirmations; Trust & Continuity; provider fulfilment and communication; then channels, public secondary pages, Agents, Admin and commerce. Work must extend the established `kurukoo-visual-system.css`, public shell, Chat selectors, workspace primitives, native `components/kurukoo-ui.tsx`, Discover composition and Admin language. It must not create a parallel visual system, route family, conversation engine, runtime, persistence model or payment/provider claim. [1] [2] [3]

## End-to-End Implementation Coverage

The implementation-level convergence pass now covers the registered surface families through existing owners: public shell/content, Chat, Desk/workspace, Discover, requests and durable work, commerce/agent boundaries, connected channels, partner and fulfilment context, Admin operations, PWA lifecycle, and shared Expo primitives. The public Features and API documentation outliers were moved onto the established public authority, the Control Room's visible readiness states now use the existing semantic vocabulary, and native More reflects its existing warning/success status tones. These changes retain the current **COMPLETE — DEVICE VALIDATION PENDING** and **EXTERNAL ACTIVATION PENDING** labels because compiled/static evidence is not a substitute for live browser, provider, payment, channel, PWA or physical-device observation. [1] [2]

## Evidence and Validation Boundary

Static checks can verify selectors, CSS duplication, HTML/EJS integrity, focus/motion rules and client contracts. They cannot prove authenticated rendering, installed PWA behavior, physical device layout, live provider availability, payment settlement, channel pairing or notification delivery. Those surfaces retain the exact **EXTERNAL ACTIVATION PENDING** or **COMPLETE — DEVICE VALIDATION PENDING** labels above until independently observed.
